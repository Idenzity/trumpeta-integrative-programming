Activity 5

Project Title:
Weather Scanner
– Simple Weather App using API

Description:

- Weather Scanner is a simple web application that allows users to check the current weather conditions of a city. The user enters a city name, and the application retrieves real-time weather data from a public API. The project demonstrates how APIs can be integrated into a web application using JavaScript to send requests, process JSON responses, and display the results dynamically in the interface. This project was developed as part of an activity to explore API integration in web development.

API Used:

- Open-Meteo API

- Geocoding API:
  Used to convert the city name entered by the user into geographic coordinates (latitude and longitude).

- Weather Forecast API:
  Used to retrieve the current weather information based on the coordinates.

Features:

- User can enter a city name
- Application retrieves the city's geographic coordinates
- Displays current weather information

Shows:

- Temperature
- Wind Speed
- Weather Code
- Handles invalid input
- Handles cases where a city cannot be found
- Handles failed API requests
- Clean user interface with styled layout

How to Use:

- Open the weather application page.
- Enter the name of a city in the input field.
- Click the Search / Get Weather button.
- The app sends a request to the API.
- The current weather data for that city will appear on the page.
- If the city cannot be found or the input is empty, an error message will be displayed.

Challenges Encountered:

- One of the challenges in building this project was understanding how to use multiple API requests together. The application first needs to call the geocoding API to obtain the latitude and longitude of the city before requesting the weather data. Another challenge was handling errors properly, such as when the user enters an invalid city name or when the API request fails. This required implementing conditional checks and displaying appropriate messages to the user. Understanding how to process JSON responses and display the data dynamically using JavaScript was also an important learning experience.
